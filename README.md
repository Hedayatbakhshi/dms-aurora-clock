# Aurora Clock

A clean desktop clock widget for [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell).

## Features

- Large digital clock with optional seconds
- Date display (day, month)
- 12/24-hour format toggle (follows system setting or forced 24h)
- Adjustable background opacity
- Custom font family support with system theme fallback

## Settings

Open the widget settings in DMS → Settings → Desktop Widgets to configure
background opacity, seconds/date visibility, font family, and 24-hour format.
